# Smart Hostel Complaint Management System

A web application for managing hostel complaints and student records.

## Features

- Student login and registration
- Complaint submission and history tracking
- Admin dashboard for complaint management
- Student management and complaint reports
- SQLite database backend with a default admin user

## Setup

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Run the app:

```bash
python app.py
```

3. Open your browser at `http://127.0.0.1:5000`

## Default Admin

- Username: `admin`
- Password: `admin123`

## Notes

- The database file is created automatically in `database/app.db`.
- Student accounts can be created from the login page or from the admin panel.
