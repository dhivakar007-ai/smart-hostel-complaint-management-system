# Smart Hostel Complaint Management System

## Overview
The Smart Hostel Complaint Management System is a web-based application that allows hostel students to submit complaints and track their status. Hostel administrators can manage complaints efficiently and update their resolution status.

## Features
- Student Login
- Admin Login
- Complaint Registration
- Complaint Tracking
- Complaint Status Updates
- Complaint History
- Dashboard for Complaint Management

## Technology Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python Flask

### Database
- MySQL

## Modules

### Student Module
- Submit Complaint
- View Complaint Status
- Complaint History

### Admin Module
- View Complaints
- Update Complaint Status
- Resolve Complaints
- Generate Reports
